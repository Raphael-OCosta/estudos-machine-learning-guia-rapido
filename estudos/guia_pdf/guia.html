O que é cada coisa

No livro de SQL você escrevia consultas em arquivos .sql. Agora o código é Python e roda em notebooks: arquivos divididos em células, que você executa uma por vez e vê o resultado logo abaixo, inclusive gráficos.

Parte 1 — Primeira vez (uns 10 minutos, só uma vez)

1.1

Abrir a pasta do curso no VS Code

  1. No VS Code, clique em File → Open Folder… e escolha C:\estudos\ml_pocket_reference.
  2. Se perguntar “Do you trust the authors…?”, clique em Yes, I trust the authors.
  3. Confira o canto inferior esquerdo: se aparecer Restricted Mode, clique nele → Trust (igual ao curso de SQL). no Explorer, as pastas .venv, dados, estudos e os arquivos ch03.ipynb…ch19.ipynb.
1.2

Abrir o primeiro notebook e escolher o ambiente (kernel)

  1. No Explorer, abra praticar → cap03_classificacao_titanic_visao_geral.ipynb.
  2. No canto superior direito do notebook há um botão Select Kernel (ou o nome de um Python). Clique nele.
  3. Escolha Python Environments… e depois .venv (Python 3.12) — o caminho termina em ml_pocket_reference\.venv\Scripts\python.exe.
    • Se a lista não mostrar o .venv, aperte Ctrl+Shift+P → Reload Window e tente de novo.
    no canto superior direito, .venv (Python 3.12.x).
⚠ O kernel certo é o que faz tudo funcionar Se escolher outro Python (por exemplo o 3.13 do computador), as bibliotecas do livro não vão estar lá e aparece ModuleNotFoundError. O VS Code lembra a escolha: você só faz isso uma vez por notebook.
1.3

Rodar as primeiras células

  1. Clique na célula de código da seção Preparação (começa com import sys) e aperte Shift+Enter. um ✔ verde à esquerda da célula e o cursor pulando para a próxima.
  2. Na seção Importações · PDF p. 24, digite na célula vazia as importações do livro (import pandas as pd etc.) e rode.
  3. Na seção Colete os dados · PDF p. 27, digite df = pd.read_excel(url) e, na linha de baixo, df.shape. Rode. (1309, 14) — 1.309 passageiros e 14 colunas.
Como funciona uma célula Cada célula guarda o que você calculou na memória (o kernel). Por isso a ordem importa: se pular a célula que cria o df, as seguintes dão NameError. Na dúvida, use Restart (barra do notebook) e depois Run All até onde você estava.
1.4

Consultar quando travar

  1. Travou numa seção? Abra estudos → cap03_… (mesmo nome do seu caderno) ao lado: clique com o botão direito na aba → Split Right. Lá está o código pronto.
  2. Para ver o resultado que o autor obteve, abra o ch03.ipynb (na raiz da pasta).
  3. Compare as saídas. Números levemente diferentes são normais: as bibliotecas mudaram desde 2019 e alguns modelos têm sorteio aleatório.
  4. Não rode o original: ele aponta para o link antigo dos dados, que saiu do ar.
1.5

Criar suas anotações dentro do notebook

  1. Passe o mouse entre duas células: aparecem os botões + Code e + Markdown.
  2. Clique em + Markdown, escreva com suas palavras o que entendeu e aperte Shift+Enter.
  3. Use + Code para testar variações sem estragar o exemplo do livro.
  4. Salve com Ctrl+S.
✔ Pronto para começar? Confira:
  • A pasta abre sem Restricted Mode.
  • O notebook mostra .venv (Python 3.12) no canto superior direito.
  • A célula Preparação rodou com ✔ verde.
  • df.shape mostrou (1309, 14).

Parte 2 — Rotina de cada sessão (60 minutos)

5 min
Preparar. PDF na página do capítulo (tabela da próxima página). No VS Code, abra o capXX do dia, confira o kernel .venv e rode as primeiras células (imports e dados).
15 min
Ler uma seção, por exemplo “Árvore de decisão”. Foque em o que a técnica faz e quando usar — o livro é direto.
25 min
Digitar e entender. No seu caderno de praticar, digite o código da seção (sem copiar e colar) e rode com Shift+Enter. Travou? Olhe o estudos/capXX. Para cada resultado, pergunte: o que é isto? Depois mude um parâmetro (ex.: max_depth=3 → 5) e veja o que acontece com a nota do modelo.
10 min
Testar. Numa célula nova, faça uma pergunta sua aos dados (ex.: “mulheres sobreviveram mais?” → df.groupby("sex").survived.mean()).
5 min
Anotar. Uma célula Markdown com o que aprendeu e as dúvidas. Salve (Ctrl+S).
Ritmo sugeridoCapítulos curtos (4, 5, 9, 11, 19) cabem em uma sessão. O capítulo 10 (Classificação, 42 páginas) vale ~6 sessões: um modelo por dia. O livro todo sai em cerca de 7 semanas.
Os capítulos 3 a 13 seguem uma história só Quase todos usam o Titanic e repetem no começo as mesmas funções (tweak_titanic, get_train_test_X_y). Isso é proposital: cada notebook roda sozinho. Você não precisa estudar essas funções toda vez — entenda bem no capítulo 3.
Você não precisa saber tudo de Python antes O livro supõe algum Python. Se travar numa linha, rode-a sozinha, olhe o resultado e anote a dúvida. O SQL que você acabou de estudar ajuda muito: df[df.age > 30] é um WHERE, e df.groupby("sex").mean() é um GROUP BY.
